| Lizard linter	|         |
| cmake			| 4.2.3   |
| bison			| 3.8.2   |
| cppcheck		| 2.19.0  |
| doxygen		| 1.15.0  |
| flawfinder	| 2.0.19  |
| git			| 2.53.0  |
| subversion	| 1.14.5  |
| npm			| 11      |

The list above is not complete and a lot more are included. A full list can be seen in the following scripts, along with the way they are installed.

- ppc-amigaos - `ppc-amigaos/scripts/setup-tools.sh`
- m68k-amigaos - `m68k-amigaos/scripts/setup-tools.sh`
- ppc-morphos - `ppc-morphos/scripts/setup-tools.sh`
